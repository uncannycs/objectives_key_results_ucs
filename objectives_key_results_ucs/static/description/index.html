See It In Action

1. User OKR Access Configuration

Navigate to the user settings and grant OKR Admin access to begin configuring organizational objectives and key results.

2. Creating a High-Level Objective

Define a new objective with details like Title, Department, Mode, and points. Easily add multiple Key Results such as 'Build Language Model', 'Design Frontend', and 'Onboard 1000 Testers'.

3. Key Result: Successful Completion

Track individual Key Results like 'Build Language Model Backend'. Observe how reaching the target points in the Confirmed stage automatically transitions its status to Successful.

4. Key Result: In Progress

Monitor active Key Results such as 'Design Frontend UI'. With progress at 60%, the system accurately reflects an 'In Progress' status, rolling up its points to the parent objective.

5. Tracking Operational Goals

Manage operational goals like 'Onboard 1,000 Beta Testers'. Record the current progress to maintain a real-time 'In Progress' status and ensure accountability.

6. Company-Level Aspirational Goals

Set company-wide targets such as 'Expand into European Market'. See how reaching a 70% progress marker effectively demonstrates the aspirational success logic.

7. Comprehensive OKR Overview

View all objectives and key results in a single, consolidated list view to evaluate overall organizational performance and goal alignment at a glance.

Frequently Asked Questions

Find answers to common questions about the Objectives and Key Results module.

1. Is this module compatible with Odoo Enterprise?

Yes, absolutely! The module is fully compatible with both Odoo Community and Odoo Enterprise editions.

2. What is Objectives and Key Results and why integrate it with Odoo?

Objectives and Key Results is a module that brings specialized dry-cleaning and laundry operations directly into the standard Odoo Point of Sale. It allows you to assign specific washing types, track urgent deliveries, and manage garment-level details without ever leaving the POS screen. .

3. Which Odoo editions are supported?

This module is fully compatible with both Odoo Community and Odoo Enterprise editions. It depends on the standard stock and sale_management modules. .

4. How do I configure the Objectives and Key Results API connection?

Simply navigate to the OKR app in Odoo and begin creating Objectives. From there, you can define parent nodes, allocate weighted Key Results, and set specific user ownership for granular tracking. .

5. Can I manually adjust the computed points?

Yes, the module is equipped with inverse point functions allowing authorized users to manually override and set points directly, providing flexible goal tracking. .

6. Does this module support Odoo 19?

Yes! The module is meticulously designed and validated for Odoo 19, utilizing the latest native list and form views for optimal performance and compatibility.

7. Does it support the 70% Aspirational Threshold?

Absolutely. The module includes math engine logic to recognize aspirational targets, automatically marking goals as Successful once progress hits 70% or more. .
